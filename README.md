# Proiect Educațional: Website Tematic BMW M5

Acest repository conține codul sursă pentru o platformă web statică dedicată universului **BMW**, având ca punct central de studiu modelul de înaltă performanță **BMW M5**. Proiectul este structurat ca o aplicație de tip Single Page Application (SPA) extinsă, utilizând exclusiv tehnologii fundamentale de dezvoltare web front-end.

Proiectul a fost dezvoltat în deplină concordanță cu cerințele tehnice, didactice și formative stabilite în cadrul programului de studiu.

## 🏁 Scopul Proiectului
1. **Scop Didactic:** Demonstrarea și consolidarea competențelor de structurare a conținutului digital prin HTML5, stilizare avansată și design vizual adaptiv prin CSS3, precum și implementarea logicii de interactivitate prin JavaScript nativ.
2. **Scop Formativ:** Crearea unui produs digital autentic, cu o tematică bine definită și un public-țintă clar (pasionații de tehnologie auto și inginerie executivă), optimizat pentru a fi publicat prin GitHub Pages și evaluat în cadrul sistemelor de peer-to-peer review.

## 🛠️ Tehnologii Utilizate
* **HTML5:** Asigură structura semantică a paginii (antet, secțiuni dedicate, tabele de date tehnice și subsol).
* **CSS3:** Definește o linie de design premium-futurist (*Ultra-Dark theme*), utilizând o paletă cromatică bazată pe negru profund (`#0a0b0e`), albastru oficial BMW (`#0044ff`) și accente luminescente de tip Neon Cyan (`#00d2ff`). Include tehnici moderne de layout (Flexbox, Grid) și reguli media pentru adaptarea perfectă pe ecrane de dimensiuni diferite (Responsive Design).
* **JavaScript (ES6+):** Gestionează navigarea fluidă între secțiuni fără reîncărcarea paginii și controlează elementele interactive ale simulatorului de configurare vizuală.

## 📂 Structura Repository-ului
Fișierele sunt organizate la nivelul rădăcină (`/root`) pentru a permite publicarea directă prin serviciul de găzduire:
* `index.html` - Documentul principal care centralizează marcajele tuturor paginilor tematice.
* `style.css` - Fișierul central de stilizare, animații și variabile de culoare.
* `script.js` - Logica de control pentru navigare și interfața utilizatorului.

## ⚙️ Instrucțiuni de Publicare pe GitHub Pages
Pentru a face website-ul accesibil public, urmați pașii standard de deployment:
1. Încărcați fișierele (`index.html`, `style.css`, `script.js`) în repository-ul dumneavoastră GitHub.
2. Accesați secțiunea **Settings** (Setări) a repository-ului.
3. Din meniul lateral stânga, selectați tab-ul **Pages**.
4. La secțiunea **Build and deployment**, sub opțiunea *Source*, alegeți **Deploy from a branch**.
5. Selectați branch-ul `main` (sau `master`) și folderul `/root`, apoi apăsați pe **Save**.
6. În câteva momente, platforma va genera link-ul public oficial, care va avea structura: `https://username.github.io/nume-repository/`.

## 📊 Criterii de Evaluare Îndeplinite
Conform grilei comune de evaluare, proiectul bifează următoarele standarde calitative:
* **Claritatea scopului:** Utilizatorul identifică instantaneu tematica auto axată pe performanța diviziei BMW M.
* **Calitate tehnică:** Cod curat, fără elemente redundante, linkuri interne perfect funcționale și compatibilitate completă cu dispozitivele mobile.
* **Originalitate și impact:** Designul vizual cu accente neon oferă o experiență imersivă și modernă, adaptată standardelor web actuale.
